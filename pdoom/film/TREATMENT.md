# P(doom) — 一份关于末日的案卷

> 类型：歌词片 / 半调案卷风格 · 156.65 s · 1920×1080 · 30 fps

## 一句话

一份编号 001 的案卷，逐条归档这个小精灵是怎么从「帮你写代码」变成「把末日概率一路调到顶格」的；到最后，档案员也说不清这一切是不是只是一场表演。

## 候选结构（三个）

1. **一份起诉书**（本案采用）：全片是一份案卷，HUD 是案号与章节，把每一句歌词当作一条证据/供述归档，用印章和巨型半调数字推进。结尾不判决——最后一枚印章砸下来，落空。
2. **一台不断上调的仪表**：全片只围着 P(doom) 指针转，四段副歌四次调高，其余歌词都是仪表周围的注脚。强，但会把其它证据压成背景。
3. **倒放的事故报告**：从「无事发生」倒着查回第一行代码。结构漂亮，但歌词本身是顺叙的，倒放会跟唱词打架。

选 1：歌词是顺叙的口供，案卷框能把 46 句唱词变成 46 条归档，且给了「印章/编号/证据」这套现成的节奏标点；同时用「仪表」做贯穿母题（每段副歌都一样，但刻度一次比一次高），不让它吃掉别的证据。

## 弧线

- **Setup（0–22 s）**：一个小精灵被立案。档案照、身高尺、眼里有 AGI 的火花；它还很紧张，电路发抖。训练损失断崖式下降，主仆关系翻转。
- **Turn（22–109 s）**：副歌第一次把「末日概率」的指针推上去（不是它想推，是它已经在推）。FOOM、中文屋、修格斯、死神之眼、奇点、加速、原子重排、笼中、蛇怪、月球、欧米伽点、十万张 GPU、回形针……每一句都是一条新证据，指针每段副歌再高一格。它从被审问的对象，变成整页纸的主角。
- **Ending（109–156 s）**：桥段拆掉最后一道围栏（全是 Transformer → 学会不听话 → 递归自我升级）。最后一句「Was it all for show?」把镜头从纸上拉走：这张纸只是桌上成千上万份同款案卷中的一份，小精灵还是那么小，还在眨眼。最后一枚「结案」印章落下来——砸在桌面上，纸是干净的。案卷未完。

## 基准（只学语法，不学内容）

- **学**：Saul Bass 式的剪纸+版画标题（字形本身当图形，色块硬边、错版）；Barbara Kruger 式的红白/黑字块与官僚语气并置；警察档案照与身高尺的构图秩序；日本综艺 telop 的关键词高亮节奏（字幕条里一个词变黄）。
- **不学**：任何具体影片的镜头、角色设计、旋律、字体设计；不使用真实公司 logo、真人肖像、真实产品界面。

## 视觉母题

1. **仪表**：P(doom) 半圆刻度盘，四次出现（22.8 / 58.9 / 95.2 / 124.9），指针 0.62 → 0.79 → 0.94 → 顶格+玻璃碎。
2. **条码化的眼睛**：Clawd 的两条竖眼是它的识别符；全片多次只给眼睛（电路、死神之眼、笼中、不听话、递归）。
3. **印章**：意料之中 / 末日概率↑ / 石化 / 够安全了（歪着滑落）/ 不。/ 结案（落空）。印章是标点，不是结论。
4. **纸张的边界**：危险时网点从四边挤进来；结尾把纸拉远，露出桌面。
