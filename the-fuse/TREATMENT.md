# 《The Fuse / 引线》—— I'm Upping My P(doom) 音乐影像

> 风格：Urban Sketch · Pen & Wash（钢笔淡彩）。全片在纸上发生：一支 0.4 mm 棕色针管笔、一块冷压水彩纸、一盒淡彩。
> 时长 156.7 s，1920×1080，24 fps。无旁白；歌词是速写本页边的手写批注，逐词出现。
> 影片是用户的片子：没有 LemoLab 署名，没有示范片的任何人物、构图、镜头或配乐。

## 0. 一句话

一个街头速写者在一个周日下午画下整场世界末日：他从陌生人的眼睛里画出第一粒橙色火星，那粒火星其实是一根引线，一路烧过他的速写本，烧到最后一页——合上书，还是下午四点十分。

## 1. 三个候选结构

**A. 一本速写本（选用）**
八张跨页：街角 → 房间 → 机房 → 天空 → 公路 → 办公室 → 纸堆 → 封面。镜头在同一张纸上运动，翻页是唯一的分段。橙色引线是贯穿全片的唯一颜色。
*为什么选它：* 风格本身就是"现场速写"，而这首歌是一个人在末日面前的碎碎念。让唱歌的人就是画画的人——歌词成为页边批注，AGI 末日成为他笔下的写生对象——风格、叙事和音乐三者第一次指向同一件事。合书即落幕，天然的书挡式结尾。

**B. 同一个街角的四个时刻**
同一页街角，清晨/正午/黄昏/深夜，墨线不动，颜色与人群换。技术上是本风格最纯正的展示。
*放弃原因：* 歌词的升级（P(doom) 从 0.02 到 1.00）需要空间上的扩张与失控，一个街角撑不住"paperclips fill the room"和"one E thirty FLOPs"。

**C. 一份《AGI 建造手册》**
每条歌词变成手册里的一步：图解、警告框、装配图、免责声明。
*放弃原因：* 理性、冷、好看，但没有人物，也没有"手"；观众不会为一份手册难过。

## 2. 主线、弧光、书挡

- **主角**：速写者（不露脸，只见手、肩、背影）。**对手/神**：他画出来的那个东西（先是陌生人眼里的火星，然后是无脸的巨人，最后是纸上的眼睛）。
- **想要**：把这个下午画完。**阻碍**：他画的东西开始自己画下去。**转折**：他发现自己一直在画的不是城市，是引线（102.46 s，"Too late now, we lit the fuse"）。
- **开端**：空白纸，手写日期 `Sun. 4:10 pm — still.`，第一笔是长椅的扶手。
- **中段**：颜色只在橙色火星经过的地方出现；每一段 P(doom) 数字被写在页边，0.02 → 0.15 → 0.42 → 0.81 → 0.99 → 1.00。
- **结尾**：镜头拉远——满页都是他画的世界末日，他合上书。封面、书名、一行小字，火星停在封面上，慢慢暗下去。日期再次出现，一模一样：`Sun. 4:10 pm — still.` 整场末日只花了一个下午。这是全片唯一的玩笑，也是全片最冷的一下。

**本片自己的规则**：橙色 `#D97757` 只属于那根线/那粒火星；任何其他颜色都必须由它"带"进画面。

## 4. 视觉系统

- **纸**：`#f5eede` 冷压纸，大块云斑 + 细齿；每张跨页都留出页边，画不到边，边缘碎成色点。
- **墨**：`#2b2520`，一笔 1.3–3.4 px（远处细、近处粗），抖、出头、偶尔断笔。
- **淡彩**：错位 1–3 px、边缘积色、颗粒；颜色永远从火星经过的地方"洇"过去（arrival field），不是整页一起上色。
- **人物**：12 fps boil；脸留白，只给一个鼻尖的侧笔；剪影必须一眼可读。
- **字**：歌词 Caveat 500，页边手写、逐词出现；日期、P(doom)、便签用 Reenie Beanie；标题 Caveat 600。所有字都在纸里，跟着镜头走。
- **每页一个色温**：街角（暖石灰/草绿）→ 房间（赭石/灰蓝）→ 机房（冷板岩/数据绿）→ 天空（暮紫/橙）→ 公路（土黄/橄榄）→ 办公室（纸白/信号红）→ 纸堆（紫罗兰/琥珀）→ 封面（亚麻/赭）。

## 6. 节拍与 cue（132.007 BPM，每拍 0.4545 s，每小节 1.818 s，第一个 downbeat 0.238 s）

- **翻页**落在 downbeat：22.055 / 38.418 / 58.417（稍提前 0.2 s 起手）/ 74.779 / 94.778 / 109.323 / 140.230；每次翻页前 0.3 s 起纸，落页那一下与鼓同帧。
- **橙色火星**：每次"P(doom)"的 `doom` 落在小节强拍（23.873 / 60.235 / 96.596 / 125.686），火星在那一帧跳一下、留一个墨点。
- **P(doom) 数字**：22.76 / 59.13 / 95.47 / 124.52 写出 0.02 / 0.42 / 0.81 / 0.99，140.0 之后在封面写 1.00。
- **画面重击**：9.52（下坠）、24.32（FOOM 鼓包）、41.34（螺旋开始）、64.10（甩向 Omega 点）、81.21（左转）、102.46（引线点燃）、118.75（GPU 铺开）——都对齐 downbeat。
- **静默**：37.3–38.4 只有纸声（break1）；92.0–94.7 几乎只有呼吸和远处的风（pre3 无鼓）；152.96 鼓停后只剩纸与火星。
- 速度曲线：verse 稳定 → chorus 加速 → 公路段放慢 → 办公室先慢后快 → 纸堆最密 → 眼睛长持（一次呼吸）→ 结尾静止。

## 8. 字幕与字

- 歌词就是字幕：写在纸上，逐词出现，位置永远在歌词所唱之物的旁边；一行写完停留到下一行开始。
- 字号：正文按画面宽度自适应，最长一行不超过画面宽的 62%；页边批注 46–60 px（世界坐标）。
- 另出 `.srt`（同词级时间，整行显示），供静音观看。
- 标题：封面手写 `The Fuse`，下面小字 `a reportage, in one sitting`（Caveat 600 / 500）。
- 片尾小字：曲目与作者、演唱版本、字体授权。没有 LemoLab 字样。

## 10. 定稿说明（制作中修订）

- **全片英文**：片中所有手写文字、便签、标签、片尾字幕均为英文，不含任何中文。风格库的署名不上片（这是用户的片子），只在 `CREDITS` 里列出引擎与字体授权。
- **歌词改为"画面下缘的页边批注"**：镜头运动幅度大（俯冲、甩镜、升降），若把字钉在纸上会被镜头甩出画外。定稿把每一句写在镜头的纸边（左/右下角，无框、无底条，只有纸色晕开），逐词出现、写完停住；下一句开始后上一句像铅笔字一样轻轻退去。这仍是"手写在纸上"，不是字幕条。
- **一处关键取舍**：橙色引线是唯一的彩色线条，它自己就是引线（fuse），不是装饰；它从她的眼睛出发，穿过每一页，最后一页停在封面上。
- **静默与留白**：37.3–38.4（break1）与 92.0–94.7（pre3）只留纸声与环境；152.96 鼓停后只剩纸与火星。
- **声音**：原曲不动；只叠一层程序合成的纸上拟音（钢笔、翻页、湿画、回形针、引线、合书），整层比音乐低约 10–14 dB，四个关键点短暂避让。

## 11. 最终剪辑（交付版）

**一句话：线是导演。**

- **镜头跟着线**：相机目标 = 火星的位置 + 一点前瞻，临界阻尼弹簧跟随（手持感），每页一条设计好的变焦曲线；当线抵达值得看的东西（她的眼睛、巨人、挂在线上的手、那只眼），相机平滑地"看过去"——不是切。全片只有 **7 次切**，就是七次翻页。
- **墨线跟着线**：每一页的底稿不是一开始就画好的。笔触的落笔时间 = 引线离它最近的那一刻（页边网格预计算），线走到哪里，哪里的建筑、树、长椅、机柜才被画出来；远离线的地方在落页后 1.5 秒内补完，保证画面不空。
- **颜色跟着线**：落页时只有落点一小片颜色；之后每一次上色，都是火星经过哪里、哪里才洇开，湿边拖在它后面。线没到的地方保持墨线——"颜色作为事件"。
