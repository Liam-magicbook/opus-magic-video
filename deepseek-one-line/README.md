# 一条线 · DeepSeek 2023—2026

60 秒 / 2048×858（2.39:1）/ 24 fps / 无旁白 / −14 LUFS / AAC 48 kHz

一支从代码渲染出来的短片：整部片子只有**一条线**，它在八章里依次变成绘图纸上的墨线、160 条专家通道、
一张收据上的损失曲线、示波器里的股价、一匹被抽丝的织物、一段点阵、一根被拉出 100 万 token 的钢尺、
一块被挤开的窄门——最后收回同一张绘图纸，收成一句问句。

每章换一套材质与构图，章内还有硬切（全片 **28 个镜头**）：同一章里换机位、换焦距、换景别，而不是靠
文字堆叠。母题不变，只有"这条线此刻是什么物件"在变。

- 成片：`out/video.mp4`（2048×858，24 fps，H.264 CRF 15，−14 LUFS / TP −1.2 dBTP，60.000 s / ≈27 MB）
- 缩略图：`out/sheet.png`（每 2 秒一格，一眼看完节奏）；`out/sheet/part1-3.png`（每 1 秒一格）
- 创作说明与镜头表：`docs/TREATMENT.md`
- 时间轴单一真源：`cues.json`（画面与配乐共用同一张事件表）

## 现在怎么跑

```bash
# 依赖：Chrome（渲染器用 puppeteer-core 驱动本机 Chrome）、ffmpeg、Python 3 + ../lib/audio
cd deepseek-one-line

# 1) 配乐（读 cues.json 的事件时刻，输出 60.000s / −14 LUFS / TP ≤ −1 dBTP）
../.venv/bin/python audio.py
#   → out/audio.wav + out/audio_spec.png（频谱图，绿色竖线=音效同步点）
#   出现 WARN: silence gap 1.25s 是 R1 的静默段，属预期

# 2) 预览（纯 HTML，不落文件）
node tools/serve.mjs            # → http://127.0.0.1:8777/index.html

# 3) 抓静帧自检
node harness/render.mjs . --stills 3,7.6,14.6,22.2,31,38,45,54   # → out/stills/tXX.XX.png

# 4) 成片（约 2 分钟）
node harness/render.mjs . --out out/video.mp4 --audio out/audio.wav \
  --workers 3 --crf 15 --mb 3 --shutter 0.5

# 5) 缩略图
ffmpeg -i out/video.mp4 -vf "fps=1/2,scale=480:-1,tile=6x5:margin=8:padding=5:color=0x111111" -frames:v 1 out/sheet.png
ffmpeg -i out/video.mp4 -vf "fps=1,scale=512:-1" out/sheet/s%02d.png
cd out/sheet && ffmpeg -i s%02d.png -filter_complex \
  "scale=384:-1,tile=4x5:margin=6:padding=4:color=0x111111" part%d.png
```

`index.html` 是唯一渲染入口：世界只有一个画布，`renderAt(t)` 把 `t` 时刻的整帧画出来，
没有 CSS 动画、没有 `Math.random()`，所以浏览器预览和离线逐帧导出完全一致。
渲染器会把时间码四舍五入后取噪点，逐帧稳定。

`--mb 3 --shutter 0.5` 是运动模糊（3 采样、半帧快门）。不加这两项画面会在快推镜时抖，
加了以后单个镜头内的运动是连续的，切点仍然是硬的。

## 「奥斯卡的要求」落到了哪些具体指标

不是把片子做长做炫，而是按剧情长片的工艺标准对齐：

- **画幅与帧率**：2.39:1 宽银幕、24.000 fps（学院放映的基准帧率），无场频抖动。
- **一镜一材质**：八章八套材质（制图纸 / 机房 / 收据 / 示波器 / 织物 / 机械 / 岩层 / 制图纸），
  没有一章复用上一章的构图语言；母题（那条线）是唯一的连续性。
- **叙事弧光**：起（无人知晓）— 承（便宜得可疑）— 转（世界为此晃了一下）— 合（安静地继续压成本），
  转折点是唯一一次真正的静默，且静默后的第一个声音是全片最轻的一个音（单音钢琴）。
- **声音三层**：房间底噪 / 拟音（线被拉、刻度计数、纸张、印章）/ 配乐（每章一个动机，
  钢琴主题在开头和结尾各出现一次，形成呼应）。响度 −14 LUFS、真峰 ≤ −1 dBTP，手机外放不会糊。
- **节奏**：8–9 秒长镜头（观察）→ 4 小节由急到静的呼吸 → 每 3 小节推进一代（加速）→ 4 小节放下（减速）。
  全片只加速一次、只静默一次，没有匀速到底。
- **可读性**：标题与数字在 4K 下仍然锐利；正文最小字号 11 px@1080 高，符合放映可读下限；
  每屏只讲一个量，橙色只给"当下的那个数字"。
- **克制**：四色（墨/骨白/信号橙/灰）、无发光球、无粒子星云、无渐变滥用、无 AI 味素材，
  所有图形都是几何与排版，不依赖任何第三方图像。
- **出处**：片尾列出数据来源，关键数字都能回溯到官方公告/技术报告/定价页或通讯社报道。

## 事实与措辞的边界

- 「−17% / $589B」是 2025-01-27 英伟达单日跌幅与市值损失的媒体口径（Reuters / Yahoo Finance / TechCrunch），
  片中写作"单日市值蒸发"，不加"因此"之类因果断言。
- 「$5.576M」按 V3 技术报告表 1（H800 @ $2/GPU·h，仅官方训练，不含前期研究与消融），片中也标了这个口径。
- 「App Store 免费榜第一」是 2025-01-26/27 的美区与 51 国口径。
- 「¥1/¥2」是 V2 32K 上下文的输入/输出价；「¥0.02」是 V4.1-Flash-1017 空闲时段缓存命中的输入价。
