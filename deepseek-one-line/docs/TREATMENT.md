# 一条线 · DeepSeek 2023—2026

60 秒 / 2048×858（2.39:1 宽银幕）/ 24 fps / 无旁白 / 中英混排

## 一句话

整部片子只有**一条线**。它从杭州一间办公室的制图纸开始，依次变成 160 条专家通道、一张收据上的损失曲线、
示波器里的股价、一匹被抽丝的织物、一段点阵、一根 100 万 token 的钢尺、一道被挤开的窄门——
最后收回同一张制图纸，收成一句话。

**线不变，材质全换。** 每章一套自己的材质与构图语言：制图纸、机房通道、收据、示波器、织物、机械、
岩层。这是代码渲染才做得到的做法——同一根线在材质里换个身份，转场即叙事，不需要解释。

## 为什么是这个结构

候选一：六个章节卡片依次翻页（信息清楚，但没有电影感，读起来像 PPT）。
候选二：一条时间轴从左到右匀速推进（时间清楚，但六代模型的节奏差别被抹平了）。
候选三（采用）：**一条线 + 八种材质 + 一次呼吸**。线是主语，材质是它此刻的处境；R1 一节是全片的"呼吸"——
音乐在这里被抽走 1.2 秒，只留一个数字。叙事弧光不在信息量，而在**起—承—转—合**：
无人知晓（2023）→ 便宜得可疑（V2/V3）→ 世界为此晃了一下（R1）→ 安静地继续把成本压下去（V3.2/V4/V4.1）。

八章之外还有一层：**章内硬切**。长镜头不是目的，观察才是。一章里如果信息换了一个层面（从"有多少条
通道"到"收多少钱"，从"曲线在跌"到"总账是多少"），就硬切到新景别，而不是让同一张图硬撑 7 秒。
全片因此是 28 个镜头，而不是 8 个。

## 节奏（100 BPM，1 bar = 2.4 s，25 bars = 60.0 s）

章切点全部落在小节线上：0 / 4.8 / 12.0 / 19.2 / 28.8 / 36.0 / 43.2 / 50.4 / 60.0。
速度不是匀速：01–02 为 8–9 秒的观察段，03 用 4 小节做一次由急到静再到缓的呼吸，
04–06 每 3 小节推进一代（加速），07–08 用 7 小节放下（减速）。全片只有一次真正的静默。
章内硬切不落在小节线上（如 3b 的 16.2 = 第 6.75 小节），它服务景别变化，不服务节拍。

## 声音设计

| 段落 | 配乐状态 | 拟音 |
|---|---|---|
| 01 | 独奏钢琴，单音，房间底噪（黑胶 + 电台静电） | 纸笔、远处空调、日期落版的闷响 |
| 02 | 卡林巴 16 分固定音型 + sub 脉冲；六个专家依次拨响 | 通道点亮的轻击、木板钟、价格阶梯两记下坠 |
| 03 | 弦乐三和弦（Bbmaj7→F/A→Gm7）+ 心跳软底鼓；钟琴下行跟着曲线 | 刻度计数（加速后锁定）、木鱼、收据撕裂、印章 |
| 04 | 太鼓从 1/4 推到 16 分 → **全部抽走 1.2 s** → 单音钢琴回来 | 股价跳水 whoosh、闷雷、静默、颤音琴与钟琴报 R1 的四个事实 |
| 05 | 玻璃质感 pad，三小节换一次和声 | 抽丝的气声、2200 个点熄灭的细碎 tick、四记金牌风铃 |
| 06 | 空气感 pad，宽混响，慢速两音动机 | 卷尺拉伸、计数器滚动、卡匣折起（胶带 + 揉纸） |
| 07 | 回到卡林巴（与 02 同动机、不同配器），收束 | 窄门穿过的一口气、KV 两道 tick、最后两次价格下坠 |
| 08 | 钢琴主题再现（`A3-E4-A4`），尾音留白；片尾只剩房间底噪与极轻 sub | 线收拢的风声、光点出画的铃声、索引落版 |

三层：底噪（房间/磁带）— 拟音（动作）— 配乐。音乐在最关键的两处让路：R1 的静默、结尾的提问。
响度 −14 LUFS，真峰 −1.2 dBTP，LRA 5.6 LU。

## 美术

- 墨 `#08090A`、骨白 `#EFEAE1`、信号橙 `#FF4D12`、灰 `#8A857C`。无第四色。
- 字体：Archivo（900/700，英文标题与数字）、IBM Plex Mono（数据、日期、脚注）、
  Songti SC（中文叙述句）、PingFang SC（中文标签）、Cormorant Italic（英文副题）。
- 每章一套材质，但共享同一套栅格：左右安全边界 150 / 1898，标题基线固定在几处，
  所以换材质时画面不"跳"，观众的眼睛有落点。
- 橙色只给"当下的那个量"：这一章的主角数字、正在发生的事件、被挤出的那道光。
- 全片颗粒 + 暗角；不使用发光球、霓虹、粒子星云、渐变滥用。
